# Mouth-movement animation assets (Phases 3 & 12)

EMPTY ON PURPOSE. The exercise content references animations here
(`mouth_animation_ref` → `<ref>.svg`), and the MouthModel component hides
itself while a referenced file is absent.

Assets are seeded ONLY after the mouth shapes have SLP sign-off — a
clinically wrong tongue or lip position modelled to a child is worse than no
model (owner ruling). Pipeline mirrors the F2 curriculum items: drafted →
SLP-reviewed → committed here, one self-animating looping SVG per distinct
mouth/face target (~12–20 loops expected across both phases; confirm the
exact list against the Phase 3 / Phase 12 exercise content before drawing).

Current placeholder refs: p3-facial-awareness, p3-lip-closure,
p3-tongue-elevation, p3-single-sound (Simplified), p12-open-vowel,
p12-sound-shaping, p12-syllable-combining.
